# birdfinder

Find recent eBird sightings near you by species or group, ranked by place,
with drive times, routes and bird photos.

Open the site, paste your own [eBird API key](https://ebird.org/api/keygen)
in settings, and set a location. Both are saved in your browser only.

Data: eBird API 2.0, OSRM routing, Wikipedia photos, OpenStreetMap tiles.
